# Статистика текущего месяца на главной

## Цель

Блок «Картина месяца» на главной должен показывать доходы, расходы и баланс только за текущий календарный месяц, начиная с первого числа, а не за всё время существования пользователя.

## Контракт периода

- Начало периода — первое число текущего месяца в `00:00:00.000` по локальному времени пользователя.
- Конец периода — текущий момент.
- Границы передаются в API как ISO-строки `startDate` и `endDate`.
- При каждом обновлении статистики период вычисляется заново, чтобы переход в новый месяц не оставлял устаревшие границы.

## Поток данных

`useFinanceData` запрашивает статистику через `transactionApi.statistics` с границами текущего месяца. Тот же запрос выполняется после изменения или удаления операции. Бэкенд уже принимает `startDate` и `endDate` и ограничивает выборку операций пользователя этими значениями.

Главная продолжает получать готовые `totalsByCurrency` и показывает для выбранной валюты:

- доходы — сумму положительных операций периода;
- расходы — сумму абсолютных значений отрицательных операций периода;
- картину месяца — доходы минус расходы.

Список последних операций и аналитика в рамках этой задачи не меняются.

## Ошибки и совместимость

Поведение обработки ошибок остаётся прежним. Метод статистики получает необязательные параметры периода, поэтому существующие вызовы без фильтра и серверный контракт сохраняют совместимость.

## Проверка

- Тест API закрепляет корректное кодирование `startDate` и `endDate`.
- Тест периода закрепляет начало в первое число локального месяца и конец в переданный текущий момент.
- Тест загрузчика закрепляет использование месячного периода при первичной загрузке и повторном запросе после изменения или удаления операции.
- После реализации запускаются целевые тесты и сборка фронтенда.
