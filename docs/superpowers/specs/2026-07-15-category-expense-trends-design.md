# Помесячная динамика расходов по категориям

## Цель

Добавить на страницу аналитики отдельный линейный график, который показывает помесячную динамику пяти основных категорий расходов за всю доступную историю транзакций.

## Интерфейс

- На странице аналитики появляется отдельная карточка «Расходы по категориям».
- График содержит до пяти линий. Каждая линия соответствует одной расходной категории и использует цвет этой категории.
- По горизонтальной оси расположены все месяцы с начала доступной истории до последнего месяца с транзакциями, включая промежуточные месяцы без операций.
- В видимой области помещается не более 12 месяцев. Если месяцев больше, область графика прокручивается горизонтально.
- При первом отображении график прокручен к последним месяцам. Пользователь может прокрутить его влево к более ранней истории.
- Под графиком находится компактная легенда с названиями категорий.
- Наведение указателя или тап по точке показывает месяц, название категории и сумму расходов.
- Если подходящих расходов нет, вместо пустого графика отображается существующий компонент пустого состояния.

## Правило выбора топ-5

Топ-5 определяется один раз для текущей выбранной валюты по сумме расходов каждой категории за всю доступную историю. Благодаря этому состав линий не меняется при выборе месяца в существующей аналитике.

В расчёт входят только транзакции с отрицательным `amountMinor`, непустой категорией и валютой, выбранной в переключателе аналитики. Суммы отображаются как положительные величины расходов. Доходные категории и положительные операции не учитываются. При равенстве итогов категории сортируются по русскому названию, затем по идентификатору, чтобы результат был стабильным.

Если расходных категорий меньше пяти, график показывает фактически доступное количество линий. Месяц без расходов по конкретной категории получает нулевое значение.

## Связь с текущей аналитикой

- Общий переключатель валюты в шапке управляет новым графиком так же, как существующими суммами и дневной динамикой.
- Выбранный таб месяца, режим месяц/неделя и переключатель «Расходы / Доходы» не фильтруют новый график: он всегда показывает всю помесячную историю расходов для выбранной валюты.
- Существующий столбчатый график дневной динамики, переход в неделю, карточки итогов и список категорий остаются без изменения поведения.

## Архитектура и данные

- Чистый helper в `src/pages/analytics/lib/analyticsPeriods.ts` формирует непрерывный список месяцев, выбирает топ-5 и возвращает серии помесячных сумм. Расчёт выполняется на уже загруженном массиве `transactions`; новый backend endpoint не требуется.
- Новый компонент `src/pages/analytics/ui/CategoryExpenseTrendChart.tsx` отвечает только за линейную визуализацию Chart.js, tooltip, легенду и горизонтальную область прокрутки.
- `AnalyticsPage.tsx` передаёт компоненту все транзакции и выбранную валюту. Данные серий мемоизируются и не зависят от выбранного месяца существующего графика.
- Для 12 месяцев используется базовая ширина видимой области. Полотно становится шире пропорционально количеству месяцев сверх 12, а контейнер получает горизонтальный скролл и начальную позицию у правого края.

## Доступность и адаптивность

- Canvas получает понятное доступное название, а легенда дублирует цвет текстовым названием категории.
- Горизонтальный скролл доступен на мобильном устройстве жестом и на десктопе обычными средствами прокрутки.
- Размер области не должен раздвигать страницу целиком: прокручивается только содержимое карточки графика.

## Проверка

Автоматические тесты должны закрепить:

- выбор пяти крупнейших расходных категорий по всей истории выбранной валюты;
- исключение доходов, положительных операций, других валют и операций без категории;
- стабильный порядок при одинаковых суммах;
- формирование непрерывной шкалы месяцев, включая пустые промежуточные месяцы;
- нулевые значения категории в месяцах без её расходов;
- отсутствие зависимости результата от выбранного месяца существующей аналитики;
- наличие карточки, заголовка и передачи выбранной валюты на странице аналитики.

После реализации запускаются целевые Jest-тесты, frontend-сборка и полный набор Jest-тестов.
