# Нормализация смешанного алфавита в OCR

## Цель

Исправлять одиночную визуально похожую букву другого алфавита внутри OCR-слова
до сопоставления банков по пользовательским названиям и ключевым словам.

## Правило

- Слово должно содержать буквы обоих алфавитов.
- В слове должна быть ровно одна буква из недоминирующего алфавита.
- Эта буква заменяется только при наличии визуально похожей пары:
  `а/a`, `е/e`, `о/o`, `р/p`, `с/c`, `х/x`, `у/y`, `к/k`, `м/m`, `т/t`,
  `в/b`, `н/h`.
- Направление замены определяется доминирующим алфавитом слова:
  `ozоn` становится `ozon`, `озoн` становится `озон`.
- Слова без однозначно доминирующего алфавита и слова с несколькими чужими
  буквами остаются без изменений.

## Интеграция

Нормализация выполняется для OCR-текста, имени файла, названий банков и
пользовательских ключевых слов перед точным и неточным сопоставлением.
Исправленная смешанная буква не расходует существующий лимит одной OCR-ошибки.

## Проверка

Тесты покрывают оба направления замены, сохранение неоднозначных смешанных слов
и совместную работу нормализации с одной дополнительной OCR-ошибкой.
