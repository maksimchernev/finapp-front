# Переключение месячного графика расходов

## Цель

Добавить месячному линейному графику расходов два режима: топ-5 категорий и общая сумма расходов.

## Поведение

- Начальный режим показывает существующие линии топ-5 категорий.
- Тап или клик по области графика переключает его на одну линию «Всего».
- Повторный тап или клик возвращает линии топ-5 категорий.
- Линия «Всего» учитывает все расходы выбранной валюты за месяц, включая категории вне топ-5.
- Линия «Всего» визуально толще линий категорий и использует нейтральный тёмный цвет.
- Легенда соответствует активному режиму.
- Рядом с графиком отображается короткая подсказка о переключении режимов.
- Переключение режима не меняет валюту и позицию горизонтальной прокрутки.

## Данные и компоненты

- `buildCategoryExpenseTrend` рассчитывает месячные значения общей суммы по всем расходным операциям выбранной валюты и возвращает их вместе с существующим топ-5.
- `CategoryExpenseTrendChart` хранит локальный режим отображения, формирует один из двух наборов Chart.js и переключает режим по событию клика графика.
- При смене валюты сохраняется выбранный режим; сам график получает новые значения для этой валюты.

## Проверка

- Тест помощника подтверждает, что «Всего» включает категории, не попавшие в топ-5.
- Тест UI-контракта подтверждает наличие двух режимов и обработчика переключения.
- После изменения запускаются целевые тесты аналитики, сборка и полный набор тестов фронтенда.
