# Определение Альфа-Банка по OCR-интерфейсу

## Проблема

На экране истории Альфа-Банка название банка может отсутствовать, а внутри операций могут встречаться названия других банков, например Ozon. Текущий детектор ищет отдельные подстроки и знает только встроенного кандидата Ozon, поэтому такой скриншот не может уверенно определить Альфа-Банк.

## Решение

Добавить Альфа-Банк как известного кандидата с двумя способами распознавания:

- прямые названия `альфа-банк`, `альфа банк`, `alfabank`;
- компактная интерфейсная сигнатура в фиксированном порядке: `Главный → Платежи → История → Чаты`.

Слова сигнатуры должны находиться рядом. Между каждой соседней парой допускается не более 24 символов после нормализации пробелов — этого достаточно для OCR-мусора, иконок и пропущенного центрального пункта меню. Четыре слова, разбросанные по разным частям скриншота, совпадением не считаются.

Если сигнатура определила известный банк, детектор сначала ищет уже существующий пользовательский банк с тем же нормализованным названием. Только если его нет, upload-flow создаёт `Альфа-Банк`. Упоминание Ozon внутри отдельной операции не должно перехватывать результат Альфа-сигнатуры.

## Границы изменения

- Изменяется только frontend-детектор банка и его тесты.
- Новые OCR-библиотеки и анализ цветов/логотипов не добавляются.
- Обычный поиск пользовательских банков по имени и ключевым словам сохраняется.
- Существующее определение Ozon по явному названию сохраняется.
- Одиночные слова `Главный`, `Платежи`, `История` или `Чаты` не определяют Альфа-Банк.

## Проверка

Тесты подтверждают:

- компактная строка меню Альфа-Банка определяется как `Альфа-Банк`, даже если в операции упомянут Ozon;
- уже существующий пользовательский `Альфа-Банк` возвращается вместо кандидата для создания;
- слишком большие расстояния между словами не дают совпадения;
- одиночные навигационные слова не дают совпадения;
- текущее распознавание Ozon продолжает работать.
